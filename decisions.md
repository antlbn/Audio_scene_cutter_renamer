
# Decisions

## UI/UX settings: первый этап

Текущий фокус: не делать весь большой settings-wizard сразу. В MVP settings
закрывает только один основной use case пайплайна и редактирует секцию
`whisper` в `config.yaml`.

- `cinema_clapboard -settings` открывает терминальный UI на InquirerPy: сначала
  главное меню настроек, внутри можно менять отдельные пункты, в конце
  `Done / Save`.
- В первом этапе доступны только:
  - язык аудиодорожки для Whisper (`whisper.language`);
  - режим Whisper: `transcribe` или `translate` (`whisper.task`);
  - локальная модель Whisper (`whisper.model_id`).
  - просмотр и удаление локально скачанных весов Whisper из `whisper.cache_dir`
    через отдельный пункт меню с подтверждением.
- Следующий UI-этап:
  - настройка `clapper.audio_model.threshold`;
  - настройка рендеринга нового имени файла через `renamer.naming_template`;
  - настройка суффикса через `renamer.suffix`.
- В JSON итогового результата поле `new_name` хранит финальное имя файла.
- Рендеринг имени файла теперь настраивается через отдельный `renamer`-блок,
  а заданный суффикс просто дописывается к шаблону без проверок.
- Язык выбирается через settings и хранится в конфиге.
- Settings UI редактирует тот же `config.yaml`, потому что один хорошо
  прокомментированный конфиг проще для пользователя. Для записи используется. Дефолтный конфиг храниться отдельно, и если надо загружается по команде из меню settings
  round-trip YAML parser (`ruamel.yaml`), а не ручная правка строк, чтобы не
  плодить костыли и сохранять комментарии.
- Python CLI (`pipeline.py`, `whisper.py`) пока оставляет `--language` и `--task`
  как dev/debug override, но пользовательский путь через wrapper идет от
  `config.yaml`.
- Остальные идеи settings, такие как rename mode, JSON рядом с файлом, output
  folder, OpenAI/cloud Whisper, .env wizard, prompt/model docs и удаление весов,
  остаются roadmap и не входят в первый этап.

 - обработка будет происходить по одному файлу за раз - вот какие команды мне нужны:
  - запустить весь пайплайн на одном файле с настройками языка (например, русский):
    ```bash
    uv run python pipeline.py claps/тест.wav --language ru
    ```
  - запустить пайплайн и сохранить результат в JSON-файл рядом:
    ```bash
    uv run python pipeline.py claps/тест.wav --save --language ru
    ```
  - запуск распознавания хлопка отдельно:
    ```bash
    uv run python clapper.py claps/тест.wav
    ```
  - запуск распознавания речи отдельно:
    ```bash
    uv run python whisper.py claps/тест.wav --language ru
    ```
  - запуск LLM-парсинга на тексте отдельно:
    ```bash
    uv run python scene_parser.py "сцена 3 дубль 2"
    ```  все равно они будут обработаны по очереди.  
 - результаты работы будут складываться в .json в который будут собираться названия файла и финальная строка результат содержащая новое предлагаемое название файла основываясь на работе программы
 - конракты между модулями должны быть простыми
